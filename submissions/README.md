## Comparisons
### Sumatra PDF
Sumatra is faster for raw PDF viewing but lacks DOCX/XLSX/PPTX support, text-to-speech, web panel, and markdown editing.

### Microsoft Word Viewer
Discontinued. EleViewer is actively maintained, supports more formats, and includes TTS + vault + session restore.

### FreeFileViewer
Ad-supported, 30-day trial limit. EleViewer is free, open-source, no trial, no ads.

### Adobe Reader
Heavy, cloud-connected, telemetry. EleViewer is ~135MB portable, offline, zero-telemetry.
